# Shim-бинарники для unit-тестов

Shim'ы подставляются в `PATH` перед реальными утилитами, чтобы тестировать
скрипт без настоящего PostgreSQL и без побочных эффектов.

## Конвенция

- Поведение shim'а управляется **env-переменными** `SHIM_<УТИЛИТА>_<РЕЖИМ>`.
- По умолчанию shim ведёт себя «как настоящая утилита» (корректный ответ
  или делегирование реальному бинарнику в `/bin/...`).
- Каждый режим сбоя — отдельная переменная, чтобы тесты были явными.

## Список

| Shim    | Режимы |
|---------|--------|
| `pg_dump` | `SHIM_PG_DUMP_FAIL=1` (ошибка), `SHIM_PG_DUMP_TRUNCATE=1` (неполный дамп) |
| `psql`    | `SHIM_PSQL_FAIL=1` (ошибка), `SHIM_PSQL_LIST="a b c"` (список баз) |
| `gzip`    | `SHIM_GZIP_FAIL=1` (ошибка), `SHIM_GZIP_CORRUPT=1` (битый архив) |
| `df`      | `SHIM_DF_MB=100` (свободное место в МБ) |

## Подключение в тесте

```bash
PATH="$SHIMS:$PATH" SHIM_PSQL_FAIL=1 bash "$SCRIPT" ...
```
